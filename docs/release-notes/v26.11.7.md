## EthernetTools 26.11.7

### New: CDP neighbours read from the switches

- Switches that answer SNMP are now also asked for their **CDP** neighbour table, not only LLDP's. A Cisco (or
  another switch that keeps CDP's table: ArubaOS does) that has LLDP off still tells its cables. A cable reported
  by both LLDP and CDP is drawn once.

### New: the switch tables behind the map

- **Map ▸ Switch tables...** in the Topology window (or double-click a switch that answered SNMP) shows the raw
  tables the map was built from:
  - each switch's **MAC table**: the device each MAC is, and how many MACs share each port;
  - its **LLDP** and **CDP** neighbours;
  - **what this PC heard** on its own port (LLDP, CDP, spanning tree with the root bridge and cost).
- Copy or export each table as CSV. Use them to see why a device is where the map puts it, or why it isn't.
