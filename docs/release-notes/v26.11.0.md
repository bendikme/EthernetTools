## EthernetTools 26.11.0

The first release of EthernetTools: finds the devices on an Ethernet network — Profinet devices in any
subnet, PCs, PLCs, printers — and gives the everyday tools for them in one window.

Unzip and run `EthernetTools.exe` — one file, the .NET runtime inside. Install **Npcap** once
(<https://npcap.com>) so it can send and capture raw Ethernet frames.

### What it does

- **Scan** an adapter: Profinet DCP Identify-All (name of station, type, IP, mask, gateway — whatever
  subnet the device is set to), an ARP sweep of the adapter's own subnet, and listening to ARP / IPv4
  traffic for devices in foreign subnets; then host names by NetBIOS and reverse DNS. Devices show up while
  the scan runs; Profinet devices are tinted, the *Source* column says how each was found.
- **Tools** for the selected device: ping, traceroute, port scan of 24 common IT and industrial ports
  (S7, Modbus, EtherNet/IP, OPC UA, …), open its web page, Wake-on-LAN, Profinet **Flash LED**, copy IP /
  MAC / row, export the list as CSV. Filter by MAC, IP, name or vendor.
- **Adapters**: every wired adapter, virtual ones too; Shift+Refresh shows why an adapter is missing.
- A new icon, and the version in the window title.

### Notes

- Npcap is needed for scanning and Flash LED; without it the window says so, and ping, traceroute and port
  scan still work.
- The file is not code-signed: Windows SmartScreen may ask before the first start.
